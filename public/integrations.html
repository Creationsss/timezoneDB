Plugins and tools that read timezones from Timezone DB. Set your timezone once here and each of them can use it.

Timezones for Equicord

A plugin for the Equicord Discord client that shows each user's local time on their profile and in message headers.

View the plugin source

Build your own

Anything that can make an HTTP request can read a timezone, and reads don't need a login. Look up one user by Discord ID, or fetch everyone at once with GET /v1/list.

Request
GET /v1/get?id=123456789

The API reference covers every endpoint, the response shapes and the CORS rules.
